# Ejemplos del caso HomeMaker (no incluidos en este repositorio)

Las referencias del kit que apuntan a `ejemplos-homemaker/` (tema hijo, mu-plugins y
scripts de construcción del caso de referencia) no se copiaron aquí: son de otro cliente.
Están en el Kit WP Elementor 4 de Orbit Lab (pídeselo a Oscar).
